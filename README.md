# League HQ

A dark-navy sports-media-style fantasy football league site for Sleeper league `1389345906586828800`.

## What is included

- Home / 2026 Preseason Special
- Live standings from Sleeper
- Weekly recap and matchup board
- Manager of the Week framework
- Pickup of the Week and transaction wire
- League news and funny headlines
- Week Ahead and matchup projections when exposed by the public feed
- Preseason Power Rankings based on the actual current roster
- Full 2026 Draft Central with 12-team scoring, grades, pick analysis, roster construction, traded-pick checks, positional grades, depth, upside, risk, draft-capital efficiency, concerns, championship outlook, and League HQ verdicts
- Requested editorial weighting target: Sleeper 50%, FantasyPros 25%, Fantasy Footballers 25%

## Data source

The site uses the public read-only Sleeper API directly in the browser. No API key is required. External expert-source labels are treated as editorial weighting targets; the page does not fabricate FantasyPros or Fantasy Footballers ranking data when a public browser-accessible feed is unavailable.
